# DroneOps Sync

DroneOps Sync is the Android app that uploads DJI flight logs from a controller or phone to DroneOps Command.

It is closed source. It comes with a DroneOps Command hosted plan from BarnardHQ (https://www.barnardhq.com).

This repository holds only the installable app, so that copies of the app installed earlier can find their update. The app updates itself from your DroneOps Command server; nothing else is published here.
